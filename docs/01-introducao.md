# Sistemas de Equações do 1º Grau — Introdução

Um **sistema de equações** é um conjunto de duas ou mais equações que precisam ser verdadeiras ao mesmo tempo, usando as mesmas incógnitas (como x e y).

Quando as equações são do 1º grau (sem expoentes maiores que 1 e sem multiplicação entre as incógnitas), o sistema é chamado de **sistema linear**. A forma mais comum, com duas equações e duas incógnitas, é:

```
ax + by = e
cx + dy = f
```

Resolver o sistema é encontrar o par de valores (x, y) que satisfaz as duas equações ao mesmo tempo.

Os métodos mais usados para resolver esse tipo de sistema são o **método da substituição** e o **método da adição**. Dependendo dos coeficientes, o sistema pode ter uma única solução, infinitas soluções ou nenhuma solução.

Sistemas assim aparecem sempre que um problema dá duas informações diferentes sobre as mesmas duas grandezas desconhecidas — por exemplo, idades de duas pessoas, preços de dois produtos ou quantidades de dois tipos de animais.

# Sistemas de Equações do 1º Grau — Conceitos

## Solução de um sistema

Uma solução é um par ordenado (x₀, y₀) que, colocado no lugar de x e y, torna **todas** as equações do sistema verdadeiras ao mesmo tempo. Por exemplo, (7, 3) é solução de um sistema formado por x + y = 10 e x − y = 4, pois satisfaz as duas equações juntas.

## Método da substituição

Isola-se uma incógnita em uma das equações e substitui-se essa expressão na outra equação. Isso deixa a segunda equação com uma única incógnita, que se resolve normalmente; depois, volta-se a uma das equações originais para achar o valor da outra incógnita.

Funciona bem quando uma das equações já tem uma incógnita fácil de isolar — como em problemas de idade, onde a soma e a diferença de duas idades são conhecidas.

## Método da adição

Soma-se (ou subtrai-se) as duas equações, membro a membro, para **eliminar** uma das incógnitas. Isso só funciona diretamente se os coeficientes dessa incógnita forem opostos (mesmo valor, sinais contrários) nas duas equações.

Quando não são opostos, multiplica-se uma ou ambas as equações por números convenientes até que fiquem opostos — só então elas são somadas. O mesmo princípio se aplica a sistemas maiores: soma-se estrategicamente subconjuntos de equações até restar uma só incógnita.

## Classificação do sistema

- **Possível e determinado:** tem exatamente uma solução.
- **Possível e indeterminado:** tem infinitas soluções.
- **Impossível:** não tem nenhuma solução.

Para um sistema ax + by = e e cx + dy = f, o valor de ad − bc decide o caso: se for diferente de zero, há uma única solução; se for igual a zero, o sistema é impossível ou indeterminado.

## Aplicações comuns

Repartição de dinheiro, cálculo de idades, contagem de cabeças e patas de animais, problemas com balanças e pesos, e proporções entre grupos. Sistemas com expoentes maiores às vezes se reduzem a um sistema linear comum trocando a variável (por exemplo, chamando x² de "a").

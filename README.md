# Guia prático sobre sistemas matemáticos de 1º grau
## Objetivo: Auxiliar estudantes do ensino fundamental (6º/7º) ano a compreender melhor o conteúdo: sistemas matemáticos, de forma teórica e prática.
## Público-alvo: Estudantes que possuem dificuldade ou não tenham aprendido o conteúdo: sistemas matemáticos.
## Pré-requisitos: Entendimento de matemática básica, equação de 1º grau, compreensão dos conceito de icógnitas e variáveis e princípio da igualdade.

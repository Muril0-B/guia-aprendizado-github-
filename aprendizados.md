# Aprendizados

- O tema sistemas de equações de primeiro grau foi utilizado como objeto para a construção do projeto, pois eu já possuía domínio sobre esse conteúdo. Dessa forma, os principais aprendizados estiveram relacionados à organização e documentação de projetos no GitHub.

- Durante o desenvolvimento, aprendi a estruturar conteúdos utilizando Markdown, organizar arquivos e criar um README adequado. Também pratiquei o uso de branches, commits atômicos, Pull Requests e resolução de conflitos de merge.

- O projeto permitiu compreender melhor a importância de manter um repositório organizado, utilizar mensagens de commit claras e realizar revisões antes de integrar alterações à branch principal.
